Auth0 · Identity · New capability

No-code tools

No-code tools let teams configure Auth0 login flows, branding and actions visually, with the code path still there for developers who want it.

My roleProduct Design Manager. Directed two designers through iterative design and validation.
TeamDesign, product and engineering across several product teams, within a global design team of 7.
DeliveryPhased, with leadership buy-in up front.
TypeVisual configuration for login flows, branding and actions.

Summary

Implementing Auth0 required writing code, which limited who inside a customer's team could set up or change a login flow. We made the case to Auth0 leadership that no-code was a strategic gap, then shipped it in phases: a visual customization panel with a live preview, and a flow builder for assembling, testing and publishing a login journey. The code path stayed available throughout. There are no published usage metrics for this project, so the outcome below is qualitative.

The problem

Setting up a login meant writing code

  • AccessAnyone on a customer's team should be able to build a login flow, not just an engineer.
  • ConfidenceA first-time user had to get somewhere useful in minutes without feeling lost.
  • ControlDevelopers who wanted the code path had to keep it, with nothing taken away.

My role

Positioning, alignment, quality bar

Product strategy

I made the case to Auth0 leadership that no-code was a strategic gap, and got buy-in for a phased delivery with design leading the non-technical user's side of it.

Cross-functional leadership

Several product teams had a stake in the login. I got design, product and engineering onto one experience direction, and kept scope in check against competing roadmaps with the engineering leads.

Design execution

I directed two designers through design and validation, set the quality bar and ran the critiques. The test at every review: would a non-technical user get through this?

The design

Configure the login, build the flow, see it live

Two surfaces: a customization panel where styles, fonts and colors update a live preview of every login screen, and a visual flow builder where a login journey is assembled from actions, tested and published.

Screen recording of the flow builder: start node, actions, test and publish.
