No-code tools

No-code tools let teams configure Auth0 login flows, branding and actions visually, with the code path still there for developers who want it.

Role
Product Design Manager
Team
1 senior product designer, 1 product designer
Time zones
3
Delivery
Phased

My role

Positioning, alignment, quality bar

Product strategy

I made the case to Auth0 leadership that no-code was a strategic gap, and got buy-in for a phased delivery with design leading the non-technical user’s side of it.

Cross-functional leadership

Several product teams had a stake in the login. I got design, product and engineering onto one experience direction, and kept scope in check against competing roadmaps with the engineering leads.

Design execution

I directed a senior product designer and a product designer through design and validation, set the quality bar and ran the critiques. The test at every review: would a non-technical user get through this?

Results

Anyone on the team can configure the login

Implementing Auth0 meant writing code, so only an engineer could set up or change a login flow. We shipped a visual customization panel with a live preview, then a flow builder for assembling, testing and publishing a login journey.

  • Phase 1Customization panel with live preview
  • Phase 2Flow builder
  • KeptCode path for developers

The problem

Setting up a login meant writing code

Only an engineer could set up or change a login flow, so every branding tweak and every new step went into a queue.

  • AccessAnyone on a customer’s team should be able to build a login flow, not just an engineer.
  • ConfidenceA first-time user had to get somewhere useful in minutes without feeling lost.
  • ControlDevelopers who wanted the code path had to keep it, with nothing taken away.

The design

Build the flow, test it, publish it

A visual flow builder where a login journey is assembled from actions, tested and published, with the code path still available throughout.

Screen recording of the flow builder: start node, actions, test and publish.

Live preview

Configure the login and see it change

The first phase: a customization panel where styles, fonts and colors update a live preview of every login screen as you change them.
