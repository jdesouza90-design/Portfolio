No-code tools

No-code tools let teams configure Auth0 login flows, branding and actions visually, with the code path still there for developers who want it.

Role
Product Design Manager
Team
1 senior product designer, 1 product designer
Time zones
3
Delivery
Phased

The problem

Only an engineer could set up or change a login flow, so every branding tweak and every new step went into a queue.

  • AccessAnyone on a customer’s team should be able to build a login flow.
  • ConfidenceA first-time user had to get somewhere useful in minutes without feeling lost.
  • ControlDevelopers who wanted the code path had to keep all of it.

How I led it

The case for it

I supported the case for building it and helped define the experience from the start.

One direction

Several product teams had a stake in the login. I got design, product and engineering onto one experience direction, and kept scope in check against competing roadmaps with the engineering leads.

Critiques

I directed a senior product designer and a product designer through design and validation, set the quality bar and ran the critiques. In every review, the test was whether a non-technical user could get through it.

Key decisions

Phase 1: a live preview

A customization panel where styles, fonts and colors update a live preview of every login screen as you change them.

Phase 2: a flow builder

A visual flow builder where a login journey is assembled from actions, tested and published, with the code path still available throughout.

Screen recording of the flow builder: start node, actions, test and publish.
